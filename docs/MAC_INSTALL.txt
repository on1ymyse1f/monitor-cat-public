AI Monitor 0.8.3 · 猫娘观测所 / 晨曲 / 夜想

支持 macOS 14 或更高版本，Apple Silicon 和 Intel。无需安装 Xcode、Swift、Python 或 Homebrew。

安装：先退出旧版 AI Monitor，再把 AIMonitor.app 拖入 Applications，选择替换旧版 App。
随后从“应用程序”打开 AIMonitor。用户数据库与设置会保留。

本包未经 Apple 公证。如果系统阻止打开，请到“系统设置 → 隐私与安全性”中选择“仍要打开”。
只对你确认来源的本地包使用该操作。不要关闭系统整体的安全保护。

界面改为“猫娘观测所”：Claude 式暖象牙底色与陶土色强调、衬线标题、Apple 式滚动渐显；
手绘猫娘以贴纸形式出现（本地由原线稿生成，不含新增图片）。点击首页的猫娘可以摸摸她。
设置 → 外观 → 动画 可关闭所有装饰动效；系统“减弱动态效果”与低电量模式始终优先。

0.8.1 新增第二主题“夜想”（设置 → 外观 → 主题）：紫黑星夜、月之镜、冰霜与时钟刻度，始终为深色。
夜想的角色来自本机的角色包（~/Library/Application Support/AIMonitor/Skins/），安装包不含任何角色图；
未安装角色包时夜想暂用猫娘。制作方法见仓库 docs/CAT_OBSERVATORY.md。

0.8.2：夜想加入 Galgame 式对话框（名牌 + 逐字显示）、飘落的玫瑰花瓣、镜面流光与闪烁星光、
镜框上的缎带与裙边蕾丝；角色改为平滑漂浮，换表情时轻轻一弹；摸摸她会冒出爱心；
切换标签时呆毛会晃一下。动效全部交给 Core Animation，以低帧率运行，无人观看时停止。

0.8.3 新增第五个标签页“小票”：把今日或近 7 天的 token 花费印成一张超市小票——模型是商品、
token 是数量、折算单价、合计；未定价的模型照样列出，但不计入金额，也不当作 $0。小票从打印机里
一格一格地走出来，切刀落下后盖上日付印；点一下正在打印的小票可直接吐完。走纸由 Core Animation 播放，
打印期间 App 主线程几乎不工作。
0.8.3 新增第三主题“晨曲”（白天，始终为浅色）：樱粉与冰蓝、六瓣冰花标记、拍立得照片里的她、
聊天气泡式台词、胶片齿孔与和纸胶带，小票换成贴进相册的票据。晨曲同样使用本机角色包
（制作时加 --skin aubade --cutout，用 macOS 自带的主体抠图在本机完成），安装包不含任何角色图。

本版保留 GPT-6 Astra 和 GPT-5.5 官方标准短上下文定价（2026-09-05 核实）。
费用为 API 等价估算，不代表 Codex 订阅账单；不推断长上下文和服务档位溢价。

新 Mac 上请先安装并使用需要监控的 AI 工具。没有本地日志时无法凭空恢复历史。
Claude/Kimi/Cursor 在线额度仍需独立开启，默认关闭。安装包不包含个人日志或凭据。

可选历史迁移：退出旧 Mac 上的 AIMonitor，再复制整个
~/Library/Application Support/AIMonitor
到新 Mac 相同位置。该目录包含私人用量历史，只在自己的设备之间传递。

验证：DMG 旁的 .sha256 文件用于核对安装包。DMG 内的 MANIFEST-SHA256.txt 用于核对 App。
BUILD-PROVENANCE.txt 和 SOURCE-SHA256.txt 记录构建提交与源码哈希，可与 GitHub Release v0.8.3 的 tag/commit 对照。
